# Basic-C-Programs
Organized C programming examples for beginners and Computer Science students, covering fundamental concepts with structured folders and well-commented source code for learning and practice.

## 📚 Topics Covered
1. Input and Output  
2. Data Types and Operators  
3. Conditional Statements (if, else, switch)  
4. Loops (for, while, do-while)  
5. Arrays  
6. Functions  
7. Pointers  
8. Pattern Programs  
9. Strings  
10. Mathematical Programs  
11. Recursion  
12. Structures and Unions  
13. File Handling  
14. Mini Projects in C

## 🛠️ How to Run
1. Clone the repository  
2. Open terminal in the project folder  
3. Compile the program:
   gcc program_name.c -o program
4. Run the program:
   ./program
